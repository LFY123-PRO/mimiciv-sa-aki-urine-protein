# Supplementary Code S1 v1.0.2

This release provides the reviewed scientific code and reproducibility documentation. Reproduction requires authorized access to MIMIC-IV v3.1, SQL extraction, and local cleaning and covariate merging to prepare the ordered analysis-ready input before executing the analysis code.

All scientific Python and SQL files are byte-identical to the reviewed S1 package. The code uses the MIT license. The portable entry point supports four mortality comparisons. Engineering validation includes 27 synthetic checks, seven SQL syntax parses, four statistical-module imports and the CLI help path. No additional clinical models were fitted for this documentation release.
